## 🤖 How I Learn

For me, learning isn't just about writing code.

I try to understand:

> Why does this work?
> What happens behind the code?
> Can I solve it another way?
> What happens if I change something?
> Can I explain it without looking at the code?

```text
Learn → Practice → Build → Break → Debug → Understand → Improve
```

**If I understand the logic, I know I'm actually learning.**
